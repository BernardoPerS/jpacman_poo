# Entrega JPacman - Funcionalidades 1 e 2

Este repositório contém a implementação das novas mecânicas de **Circuitos, Interruptores e Portões** (Feature 1) e o novo item coletável **Pulso de Fase** (Feature 2) para o projeto JPacman.

## Localização do Projeto
* O código-fonte executável e implementado está localizado no diretório: `src/main/java/nl/tudelft/jpacman/level` e pacotes associados.
* Os mapas de demonstração estão localizados nas pastas: `conversas/feature/arquivos/`.

## Interações com LLM (Uso de Inteligência Artificial)
* **Feature 1 (Circuitos, Portões e Interruptores):** Foi utilizada **1 conversa** com a LLM para auxiliar na arquitetura, *pair programming* e debug de colisões.
* **Feature 2 (Pulso de Fase):** Foram utilizadas **0 conversas**. Não houve nenhuma consulta ou pesquisa à LLM durante o desenvolvimento desta funcionalidade, sendo implementada de forma inteiramente autônoma.

## Materiais Complementares Incluídos
Além do código executável da aplicação, esta entrega inclui:
1. **Mapas de Teste:** Mapas específicos de cada etapa de implementação.
2. **Instruções de Execução:** Detalhes para compilação detalhados no código, sem limitações conhecidas restando após os testes.
